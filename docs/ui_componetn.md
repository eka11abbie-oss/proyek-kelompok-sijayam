# Daftar Komponen UI - Proyek Sijayam

## 1. Halaman Landing Page
* **Navbar:** Logo, menu navigasi, dan tombol "Login".
* **Hero Section:** Judul utama aplikasi dan tombol Call-to-Action (CTA).
* **Footer:** Hak cipta dan informasi kontak.

## 2. Halaman Login
* **Card Container:** Kotak pembungkus form login.
* **Form Input:** Input text untuk Username dan Password.
* **Button:** Tombol "Masuk".

## 3. Halaman Dashboard
* **Sidebar Navigation:** Menu pintas pindah halaman.
* **Header Profile:** Menampilkan nama user yang login.
* **Data Table:** Komponen untuk menampilkan list data utama proyek.
