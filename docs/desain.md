# FRONTEND DEVELOPER - UTS PROJECT SUBMISSION

## Tugas Frontend Developer

Sebagai Frontend Developer, tugas utama pada fase UTS adalah memastikan bahwa desain antarmuka aplikasi sudah terdokumentasi dengan jelas dan dapat digunakan oleh tim saat memasuki fase coding setelah UTS.

### Checklist Pengerjaan

#### 1. Memastikan Link Mockup UI Sudah Ada di docs/DESIGN.md

Frontend Developer wajib memastikan bahwa link desain UI seperti Figma atau Canva sudah tercantum dengan jelas pada file:

```text
docs/DESIGN.md
```

Contoh penulisan:

```md
## Link Mockup UI
https://www.figma.com/design/Lpzp0mMBd6zHuoZvyFYTMb/Restaurant-Food-Landing-page%F0%9F%98%8B--Community-?t=yzrer7TM2Va6kOAc-0
```

---

#### 2. Memastikan Mockup UI Minimal 3 Halaman

Mockup UI harus memiliki minimal:

* Landing Page
* Login Page
* Dashboard Page

Tujuan:

* Memberikan gambaran tampilan aplikasi
* Menjadi acuan frontend saat proses implementasi coding

---

#### 3. Memastikan File docs/ui_components.md Sudah Lengkap

File:

```text
docs/ui_components.md
```

harus berisi daftar komponen UI yang digunakan pada aplikasi, seperti:

* Navbar
* Hero Section
* Login Form
* Menu Card
* Dashboard Section
* Footer
* Button Components
* Form Components

---

#### 4. Final Check Repository

Frontend Developer juga membantu tim memastikan:

* Tidak ada conflicted files
* Struktur folder project rapi
* Dokumentasi frontend sudah lengkap
* Semua perubahan sudah di-commit dan di-push ke GitHub

---

## Kesimpulan

Pada fase UTS, Frontend Developer bertanggung jawab memastikan kesiapan desain antarmuka aplikasi agar proses pengembangan frontend setelah UTS dapat berjalan lebih terarah, konsisten, dan sesuai dengan mockup yang telah dibuat.
