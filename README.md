# Dokumentasi Desain Aplikasi - Sijayam

## 1. Ide Besar Aplikasi
Aplikasi ini dirancang untuk menyelesaikan masalah pengelolaan data dan mempermudah sinkronisasi kerja antara tim secara digital. Target utama dari aplikasi ini adalah pengguna yang membutuhkan efisiensi dalam pencatatan tugas sehari-hari.

## 3. Alur Pengguna (User Flow) Utama
1. Pengguna membuka Landing Page dan menekan tombol Login.
2. Pengguna memasukkan kredensial di Halaman Login.
3. Setelah sukses, pengguna akan diarahkan ke Halaman Dashboard utama untuk mengelola data.
